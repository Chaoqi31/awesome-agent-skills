## How to Use

Most skills can be installed via your agent's skill marketplace or by copying the SKILL.md files into your agent's skills directory.

### Hermes Agent
```bash
# Copy skill to your Hermes skills directory
cp -r skill-name ~/.hermes/skills/
```

### Claude Code
```bash
# Install via plugin (if supported)
/plugin install owner/repo
```

### Codex / OpenCode
Follow the repository-specific installation instructions in each skill's README.
